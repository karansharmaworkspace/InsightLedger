About the Project

InsightLedger is a Universal Industrial P&ID Digitization Suite that automatically detects, classifies, and extracts symbols from Piping & Instrumentation Diagrams.


Key Features:

  • 32-class YOLOv8 symbol detection with SAHI tiled inference
  • 605-subclass reclassification using DINOv2 embeddings
  • Topology reconstruction with line type classification
  • DEXPI JSON, GraphML, CSV export formats
  • Knowledge graph with cross-document entity linking
  • OKF (Open Knowledge Format) integration
  • AI-powered assistant for document Q&A

Tech Stack:

Python PyTorch YOLOv8 DINOv2 PyQt6 Flask Groq LLM
